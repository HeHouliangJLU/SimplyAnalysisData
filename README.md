# SimplyAnalysisData
简单处理数据
我需要写一个分析脚本，分析数据的均值、3sigma、斜率、最大值、最小值等，要求将数据解析、数据处理、数据结果存储模块解耦。数据来源：某网站通过url接口下载的zip包，需要对zip包进行解压（解压需借鉴winrar的解压方式，因为使用win11资源管理器解压会失败），解压后将包含多个csv文件，文件名按时间排列，每个文件包含一段时间，所有文件的对应的时间连续。csv文件的前3行为表头，说明数据的名称，第一列为时间戳数据，第二列及往后为很多数据，数据最多不多于255项。数据处理时，我希望能按用户输入的时间段自动选取要处理的csv文件，并读取文件中的数据，计算数据的均值、3sigma、斜率、最大值、最小值等。由于数据量较大，多达上一条，我不希望全部读取后再计算，请采取分段处理的策略，输出分段结果和总结果。同时，一个压缩包内可能不会包含用户需要的所有时段，这时候需要根据url规则去重新下载下一段数据的压缩包，重复以上操作。我不希望数据把本地硬盘挤爆，请合理管控内存。
